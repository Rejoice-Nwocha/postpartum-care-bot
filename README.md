# 🤱 Postpartum Care Sister Bot

A culturally sensitive WhatsApp bot supporting new mothers in sub-Saharan Africa during the critical postpartum period.

## Features
- Safety-first regex scanner for emergencies
- Empathetic, motherly tone
- Regional African healing traditions (West, East, South, North)
- Scheduled check-ins (Day 3, 7, 14)
- Human nurse escalation

## Tech Stack
- FastAPI
- SQLAlchemy
- WhatsApp Cloud API

## Setup
1. cp .env.example .env
2. Fill in Meta WhatsApp credentials
3. uvicorn app.main:app --reload

Made with love for African mothers.
